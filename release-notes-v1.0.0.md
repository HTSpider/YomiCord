## YomiCord v1.0.0

Initial public release of YomiCord.

### Highlights
- Japanese sentence breakdown directly inside Discord
- Word, grammar, sentence, and kanji mining workflows
- AnkiConnect integration with configurable deck, model, and field mapping
- Kanji meaning / Kun / On support
- Duplicate detection with quick open action in Anki Browser
- Optional clipboard/message image auto attach
- Setup tab with onboarding and AnkiConnect troubleshooting guidance

### Included in this release
- Standalone plugin source repository
- Desktop native helper bridge
- Release-style README for setup and sharing
